
# Phishing Awareness & GoPhish Simulation

## 📌 Project Overview

This project focuses on improving employee awareness against phishing attacks through an authorized security awareness simulation.

The project uses **GoPhish** to conduct controlled phishing simulations, analyze user interactions, and identify areas where employees need additional security training.

## 🎯 Objectives

- Educate employees about phishing attacks.
- Conduct authorized phishing simulations.
- Measure employee awareness and responses.
- Analyze simulation results.
- Prepare a security awareness report.
- Recommend security improvements.

## 🛠️ Tools Used

- GoPhish
- Email Simulation
- Security Awareness Training
- Basic Log/Result Analysis
- GitHub

## 🔄 Project Workflow

1. Get management authorization.
2. Prepare a controlled phishing campaign.
3. Use approved internal test email accounts.
4. Send simulated phishing emails using GoPhish.
5. Monitor user interactions.
6. Analyze the results.
7. Prepare a security awareness report.
8. Provide recommendations and training.

## 📊 Key Metrics

- Emails Sent
- Emails Opened
- Links Clicked
- Reported Phishing Emails
- User Interaction Rate
- Awareness Improvement

## 🔐 Security & Ethics

This project is performed only for **authorized security awareness training**.

- No real passwords or sensitive credentials are collected.
- Only approved test users are included.
- User privacy is protected.
- Results are used for education and security improvement.
- No unauthorized phishing or credential harvesting is performed.
