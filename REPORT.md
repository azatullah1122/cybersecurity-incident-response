# Phishing Awareness Simulation Report

## 1. Project Overview

This project was conducted to evaluate employee awareness of phishing attacks through an authorized and controlled phishing simulation using GoPhish.

The main purpose was to identify common user behaviors, improve phishing awareness, and provide security recommendations.

## 2. Objectives

- Test employee awareness of phishing emails.
- Identify common phishing-related risks.
- Analyze user interactions with simulated emails.
- Improve security awareness.
- Provide recommendations for future training.

## 3. Tool Used

**GoPhish** was used to create and manage the authorized phishing awareness campaign.

## 4. Methodology

The simulation followed these steps:

1. Obtain prior authorization.
2. Prepare a safe phishing simulation.
3. Use approved test email accounts.
4. Configure the campaign in GoPhish.
5. Send simulated phishing emails.
6. Monitor campaign interactions.
7. Analyze the results.
8. Prepare the security awareness report.

## 6. Findings

The simulation showed that some users may have difficulty identifying suspicious emails, especially emails containing urgent requests, suspicious links, or misleading messages.

Users who reported the simulated phishing emails demonstrated better security awareness.

## 7. Risk Assessment

### High Risk
- Clicking suspicious links.
- Entering information on unknown websites.
- Trusting urgent or unexpected requests.

### Medium Risk
- Opening suspicious attachments.
- Not verifying the sender.

### Low Risk
- Reporting suspicious emails.
- Verifying messages before taking action.

## 8. Recommendations

- Conduct regular phishing awareness training.
- Teach employees how to identify suspicious links and senders.
- Encourage users to report suspicious emails.
- Enable multi-factor authentication (MFA).
- Use email security and anti-phishing controls.
- Conduct periodic authorized phishing simulations.

## 9. Security & Privacy

This simulation was designed for security awareness and training purposes.

- Only authorized users should be included.
- No real passwords should be collected.
- Sensitive information should not be stored.
- Campaign results should be handled confidentially.
- Simulations should follow organizational policies and applicable laws.

## 10. Conclusion

The phishing awareness simulation helps identify weaknesses in employee awareness and provides an opportunity to improve organizational security.

Regular training, user awareness, MFA, email security controls, and periodic simulations can significantly reduce the risk of successful phishing attacks.
